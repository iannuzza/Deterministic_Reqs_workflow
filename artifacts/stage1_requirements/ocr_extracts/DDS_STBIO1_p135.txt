It’s possible remap the whole AFE register map with AHB addresses  column “AHB Start 
Address” of Table 34), included the AFE_BLOCK block: in this case each registers is accessible 
with own AHB address (AHB start address + offset) and the I2C/SPI access to these registers 
must follow the previous procedure. To do that: 
• Set the user_mode at 1 (set first bit-field of CTRL_REG_7 (0x5E), one of I2C/SPI 
Internal Configuration Registers).  
This procedure is useful when you are thinking of configuring the STBIO1 by ISPU (with a code 
previously charged in code memory), leaving to host interface (I2C/SPI) the rule to collect the 
data from FIFO after AFE sampling and processing phases. 
The same procedure can be used also to consider the Regmap only for AHB, allowing the host 
interface to convert the I2C/SPI Transaction into AHB Transaction. 
 
Pay Attention: is strictly recommended to change the user_mode only when the Device is in 
IDLE STATE (check DEVICE_STATUS_REGISTER in REGMAP).
