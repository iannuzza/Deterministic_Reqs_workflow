13.2.1.1. ADSP Peculiar Requirements 
 
[DDS_STBIO1_0010] Definition: 
ADSP is responsible for managing signals for the OTP 
memory H9A_FU_OTPHV_85AL05_23A_MIM5_6ML_ALUCU/2.6.b-00, which are required for 
its reading, programming and testing procedures. 
The selected OTP memory has a data bit cut size of 640 bits with an 8-bit word size. 
Each data bit is physically redundant to optimize memory yield. Consequently, the OTP memory 
is organized into 2 banks, each containing 80 addresses of 8-bit size. 
[End]
