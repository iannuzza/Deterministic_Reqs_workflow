13.1.2.3. DCCK Requirement 
 
 
 
 
[DDS_STBIO1_390] Assumption 
O_DCCK_P_i(A2D input) will be “1” in floating electrode P state else it will be “0”  
[End] 
 
DDS_STBIO1_391] Assumption 
O_DCCK_N_i(A2D input) will be “1” in floating electrode N state else it will be “0”  
[End] 
 
 
 
[DDS_STBIO1_392] Requirement 
If O_DCCK_P_i changes its value from '0' to '1' and DCCK_IRQ_MASK is set to '1', 
then irq_DCCK_IRQ_ST, output of u_regmap_otp, shall be set to '1' 
[End] 
 
[DDS_STBIO1_393] Requirement 
If O_DCCK_N_i changes its value from '0' to '1' and DCCK_IRQ_MASK is set to '1', 
then irq_DCCK_IRQ_ST, output of u_regmap_otp, shall be set to '1' 
[End] 
 
[DDS_STBIO1_394] Requirement 
If O_DCCK_P_i changes its value from '1' to '0' and DCCK_IRQ_MASK is set to '1', 
then irq_DCCK_IRQ_ST, output of u_regmap_otp, shall be set to '1' 
[End]
