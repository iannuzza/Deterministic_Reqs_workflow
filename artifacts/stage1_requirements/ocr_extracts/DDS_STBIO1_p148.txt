15.3.1. ECG Only  
This configuration generates each time slot, two averaged ECG data, which are ECG AC and 
ECG DC, respectively. 
 
1. TIME SLOT LENGTH:  
[DDS_STBIO1_0118] Requirement: 
• The user shall configure time slot duration in DEVICE_CONFIG_OPERATION 
register [4:2] [TO: IPOS_MAIN_CTRL] [END] 
2. SELECT CHANNEL: 
[DDS_STBIO1_0119] Requirement: 
• The user shall select active channel, in this case only ECG0_SEL and DS_SEL 
(Data Storage Mode) in DEVICE_CONFIG_CHANNEL register writing  0x21. [TO: 
IPOS_MAIN_CTRL] [END] 
3. SELECT DIVISION INDEX FOR CONFIGURED CHANNELS: 
[DDS_STBIO1_0120] Requirement: 
• The user shall select a division index for ECG, configuring M_ECG_l and 
M_ECG_h in SET_ECG_FREQ_l register and SET_ECG_FREQ_h register. [TO: 
IPOS_MAIN_CTRL] [END] 
4. CONFIGURE ADC SAMPLING PERIOD: 
[DDS_STBIO1_0121] Requirement: 
 
• The user shall set the number of clocks for sampling ECG data from ADC in 
ADC_CONFIG_ECG register. [TO: IPOS_MAIN_CTRL] [END] 
5. GENERAL CONFIG: 
[DDS_STBIO1_0122] Requirement: 
• The User shall set at 1 HC_EN in ECG_CTRL register. [TO: IPOS_MAIN_CTRL] 
[END] 
6. SELECT OPERATIVE MODE: 
[DDS_STBIO1_0123] Requirement: 
 
• The user shall start measurement writing register 
DEVICE_CONFIG_OPERATION [0] at 1. [TO: IPOS_MAIN_CTRL] [END] 
7. CHECK DATA: 
[DDS_STBIO1_0124] Requirement: 
• To check data in unique FIFO (default config) the user shall check the first MSB 
which will have to be equal to the table in DATA TAG Table. [TO: 
IPOS_MAIN_CTRL] [END]
