5.11. Average Block 
5.11.1. IP Description 
This block oversees the “cleaning” of the samples doing simple average math operation and 
change representation. The output will be 16 bit for ECG, BIA and GSR, 20 bit for PPG instead. 
For ECG, BIA and GSR the number of acquisitions is fixed, while for PPG is configurable.
