5. Main Controller Top 
5.1. Description of Main Controller 
The Main Controller is in charge of generating and receiving all the control signals for the Analog 
Domain, furthermore, performs DSP elaboration on ADC Output and writes it in different 
Address. This block IP is divided into different sub-blocks, all at the same hierarchy level and 
described in the next chapter. Together with the Analog Domain, this block is interfaced with the 
FIFO Controller, the ADSP and the PMU, these last two will not be described in this document. 
The block IP is divided into different sub-blocks, all at the same hierarchy level and described in 
the next chapter.
