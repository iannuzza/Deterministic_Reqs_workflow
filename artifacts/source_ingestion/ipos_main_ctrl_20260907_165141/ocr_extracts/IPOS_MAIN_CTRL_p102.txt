5.10.3. Requirements 
[IPOS_STBIO1_MAIN_CONTROLLER_126]  REQUIREMENT : 
When ALC_COMP starts, o_BTIA_gain (2:0) shall be set at i_gain_start 
(PPG_ALC_CONFIG_PARAM_2 register [4:2]) and o_w_BTIA_ALC (8:0) shall be set at 
100000000. [END] 
 
[IPOS_STBIO1_MAIN_CONTROLLER_127]  REQUIREMENT : 
ALC cycle algorithm shall be done until the set of the last o_w_BTIA_ALC bit. [END] 
 
[IPOS_STBIO1_MAIN_CONTROLLER_ 728] REQUIREMENT : 
At the end of ALC compensation, if ALC is not masked, o_w_BTIA_ALC relative to the running 
frame, shall be set to output system (check when i_end_of_compensation rise in PPG FSM). If 
it’s masked, its contribution shall be 0 [END] 
 
[IPOS_STBIO1_MAIN_CONTROLLER_ 6129] REQUIREMENT : 
When i_ALC_comp_start is set to 1, the first rise of the o_comp_rx_ck shall happen at least after 
a T1+T_TIA_On time, both configurable by regmap. [END] 
 
[IPOS_STBIO1_MAIN_CONTROLLER_129]  REQUIREMENT : 
When i_ALC_comp_start is set to 1 and the o_BTIA_ALC (ALC Compensation) change is value, 
after a configurable time T1 (PPG_ALC_CONFIG_PARAM_1 register [3:0]), o_comp_rx_ck 
shall be high. [END] 
 
[IPOS_STBIO1_MAIN_CONTROLL  ER_130]  ASSUMPTION : 
After T1+T2, if i_comp_rx_out is equal to 1, o_w_BTIA_ALC [cycle] shall be set to 
COMP_RX_OUT. [END] 
 
[IPOS_STBIO1_MAIN_CONTROLLER_131]  ASSUMPTION : 
After T1+T2 o_w_BTIA_ALC [cycle - 1] shall be set to 1, until cycle is greater than zero. [END] 
 
[IPOS_STBIO1_MAIN_CONTROLLER_132]  REQUIREMENT : 
After T1+T2 (PPG_ALC_CONFIG_PARAM_2 register [1:0]), if o_BTIA_gain (2:0) < 
i_gain_max_set (PPG_ALC_CONFIG_PARAM_2 register [7:5]), during ALC_COMPENSATION 
state of PPG fsm with o_end_compensation set to 0, o_BTIA_gain increase its value of 1. 
Instead, if o_BTIA_gain 2:0) >= i_gain_max_set (PPG_ALC_CONFIG_PARAM_2 register [7:5]), 
o_BTIA_gain shall remain at its old value. [END]
